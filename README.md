# YouTube 相場予想集計＆動画素材生成システム

YouTubeのコミュニティ投稿や動画のURLを入力するだけで、コメント欄の金額予想（例: 海鮮丼の価格当てクイズ等）を自動集計し、**統計ダッシュボード**および**動画制作用の透過テロップ素材（16:9透過PNG / ピタリ賞カード / トーク用台本メモ）**を一瞬で作成できるWebシステムです。

---

## 🌟 主な機能と特徴

1. **ワンクリックでコメント自動収集・解析**
   - コミュニティ投稿（https://www.youtube.com/post/...）、通常動画、YouTube Shortsの全URLに対応。
   - 外部APIキー不要で、URLを貼り付けるだけで全コメントを取得・解析します。

2. **自然言語からの高精度な金額抽出エンジン**
   - 「3500円」「4,980円（税別）」「3千5百円」「3.5k」「3500〜4000円」「4000くらい」等の激しい表記揺れを完全自動正規化。
   - 「100億円」「1円」等のボケ・ネタコメントを外れ値として自動検知・除外。
   - 「ウニが乗っているから」「築地価格」などの予想理由コメントも抽出。

3. **正解発表 ＆ ピタリ賞・ニアピン賞シミュレーター**
   - 正解金額（例: 2,800円）を入力すると、ピタリ賞（完全正解者）やニアピン賞（惜しかった人）を即座にピックアップ。
   - 「視聴者の平均予想（3,850円）より 1,050円 安かった！」などの動画トーク用台本メモを自動生成。

4. **動画編集者向け素材 1クリックエクスポート**
   - **16:9 フルHD 透過PNGグラフ**: Premiere Pro / Final Cut / CapCut / AviUtl のタイムラインに乗せるだけで完成する高解像度グラフ。
   - **正解発表＆ピタリ賞カード**: 動画内で発表できるリッチなグラフィックカード。
   - **CSVダウンロード**: 投稿者名、予想額、コメント本文、いいね数などの全データ保存。

## 🚀 起動方法

### 方法1: バッチファイルから起動（おすすめ）
1. un.bat をダブルクリックします。
2. 自動的にブラウザが立ち上がり、http://127.0.0.1:8000 にアクセスできます。

### 方法2: コマンドラインから起動
`ash
python -m uvicorn backend.main:app --host 127.0.0.1 --port 8000
`
ブラウザで http://127.0.0.1:8000 を開きます。

## 🎯 画面の使い方

1. **URLを入力**:
   - 上部の入力欄にYouTubeのコミュニティ投稿URLまたは動画URLを貼り付け、「データを集計」をクリックします。
   - 「TOMIKKU NETさんの海鮮丼クイズ投稿」ボタンを押すと、サンプルのURLで即座にお試しいただけます。
2. **統計データとグラフを確認**:
   - 視聴者の予想平均額、中央値、最頻価格帯、ヒストグラム分布が表示されます。
3. **正解金額を入力**:
   - 「正解発表」エリアに実際の価格を入力し、「判定」を押すと、ピタリ賞や台本メモが生成されます。
4. **動画素材をダウンロード**:
   - 「透過PNGを保存」や「正解発表カードを保存」ボタンを押すことで、動画編集用の画像をダウンロードできます。
